# ブルーオーシャンスター株式会社 コーポレートサイト

輸出入通関業務・国際物流サービスを展開するブルーオーシャンスター株式会社のコーポレートサイトです。
React（Vite + React Router）で構築しています。

## ページ構成

| ページ | パス | 内容 |
| --- | --- | --- |
| TOP | `/` | ヒーロー / 実績数字 / サービス概要 / お知らせ / CTA |
| 会社概要 | `/about` | 会社情報・代表挨拶・沿革・アクセス |
| サービス一覧 | `/services` | 輸出入通関業務・国際物流コンサルティング・スマート物流・料金 |
| 商品別対応ガイド | `/goods` | 商品カテゴリ別の輸出入ポイント |
| お役立ち情報 | `/blog` | HSコード・通関規制・貿易実務コラム一覧（カテゴリ絞り込み） |
| よくあるご質問 | `/faq` | FAQ（アコーディオン） |
| お問い合わせ | `/contact` | 法人向け／個人向け見積り・一般お問い合わせフォーム |
| 採用情報 | `/recruit` | 募集要項・働く魅力 |

## 開発

```bash
npm install
npm run dev       # 開発サーバー起動（http://localhost:5173）
npm run build     # 本番用ビルド（dist/ に出力）
npm run preview   # ビルド結果のローカル確認
```

## 技術構成

- React 19 + Vite
- React Router（クライアントサイドルーティング）
- プレーンCSS（`src/index.css` に共通デザイントークン、`src/App.css` にコンポーネント別スタイル）
- コンテンツは `src/data/siteData.js` に集約（会社情報・サービス・FAQ・記事・求人などを一元管理）

## 備考

- お問い合わせフォームは現状フロントエンドのみのデモ実装です。実運用時はメール送信・reCAPTCHA・管理画面連携などバックエンドの実装が必要です。
- ブログ記事・商品別ガイドの本文はダミーコンテンツです。CMS連携（WordPress / Headless CMS）を想定した差し替えがしやすいよう、`src/data/siteData.js` にデータを分離しています。
